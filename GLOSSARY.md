# Glossary

### Insomnia v4 Format
Legacy export format generated by Kong Insomnia. Uses a flat `resources` list where items define `_id`, `parentId`, and `_type` (`workspace`, `request_group`, `request`, `environment`).

### Insomnia v5 Format
Current export format generated by Kong Insomnia. Identified by `type: collection.insomnia.rest/5.0` (or `*.insomnia.rest/5.x`) and `schema_version: "5.1"`. Uses a nested tree under `collection` where folders specify `children` and requests contain nested settings, parameters, and scripts.

### Variable Scoping (`_.` Notation)
Insomnia template syntax where environment variables are accessed via the `_.` property prefix (e.g., `{{ _.base_url }}`). ApiArk uses unqualified template syntax (`{{ base_url }}`).

### Environment Inheritance
Mechanism where sub-environments (`Dev`, `Prod`, `Local`) inherit values from a parent Base Environment and selectively override keys. ApiArk environments are standalone files, so inheritance is resolved into merged variable sets.
